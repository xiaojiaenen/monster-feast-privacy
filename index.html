一 我们如何收集和使用您的个人信息

游戏运行和本地记录

游戏会在设备或小游戏运行环境的本地存储中保存关卡进度、当前对局、游戏内星光及道具、签到记录、每日挑战成绩、伙伴与主页状态，以及音乐、音效、震动和动效偏好，用于恢复进度和保留设置。星光和道具为游戏内虚拟数据，当前游戏业务代码没有接入真实货币支付功能。

游戏还在本地保存访问日期、功能使用次数、关卡开始／失败／通关次数及通关用时等汇总运行记录。访问日期记录保留最近31个日期。这些游戏业务记录不由开发者上传至自建服务器，也不用于跨应用追踪或个性化广告。

运行环境会读取设备及系统基础信息，例如系统版本、平台类型、屏幕尺寸和像素比例，用于画面适配与兼容性处理。上述运行适配不需要读取通讯录、短信、通话记录或精确位置。

图片关卡和设备权限

在提供图片关卡功能的版本中，只有您主动点击选图后，游戏才读取您选择的图片，在本地解析其颜色、轮廓并转换为关卡数据；转换后的关卡数据可保存在本地，以便再次游玩。游戏业务代码不将图片或转换结果上传给开发者服务器。

支持拍照的运行环境可能提供相机入口；相机仅在您选择拍照并授权后使用。选择已有图片时使用系统或平台提供的选择器，不主动遍历整个相册。拒绝相机或图片访问不影响普通关卡。您可以在设备或平台的权限管理中撤回授权。

网络能力用于运行平台资源加载及已提供的平台功能，由操作系统或平台管理，不将其描述为所有 Android 设备都会弹窗询问的可选权限。图片选择与相机权限在具体功能触发时按系统或平台要求申请。当前游戏业务功能不申请麦克风、通讯录、短信、通话记录或精确定位权限。

排行榜和分享

游戏保存本地最高关卡和每日挑战成绩。当前平台排行榜代码通过微信兼容开放数据接口提交关卡数、挑战日期、通关用时及普通／助力分类，并在平台开放数据域内展示好友昵称、头像和成绩。只有运行环境提供这些接口时，该功能才可用；游戏没有另行建立开发者排行榜服务器，也未接入独立的 TapTap 登录或排行榜 SDK。

分享由您主动触发，分享内容包括游戏标题、宣传图片及关卡或挑战参数，由运行平台发送给您选择的接收对象。游戏业务代码不读取通讯录，不自动向好友发送消息。相关平台接口不可用时，分享和平台好友榜不可用，不影响普通关卡。

注册 实名认证和充值

当前游戏业务代码没有独立账号注册、手机号登录、实名信息收集或真实货币充值功能，因此不要求您向开发者提交手机号、密码、身份证件信息或银行卡信息。平台自身提供的账号及实名服务以平台实际告知为准。

我们只为上述目的处理相应信息，不将图片或本地游戏记录用于广告画像。改变处理目的或新增信息类别时，将事先告知并依法取得必要同意；法律规定可以不以同意为依据的处理，仅在适用的法定条件及必要范围内进行。

二 我们如何保存您的个人信息

本地游戏数据保存在您的设备或小游戏运行环境中，通常保留至您清除游戏数据、清除小游戏缓存或卸载应用；实际清理范围受设备和平台机制影响。清理后本地进度可能无法恢复。平台排行榜数据与本地存档分开保存，清除本地数据不等于删除平台上的成绩。

访问日期记录只保留最近31个日期；本地每日挑战历史也仅保留最近31个日期。本地游戏存档用于持续恢复游戏，直至您清除数据或相应运行环境删除记录。开发者未设置用于接收本地游戏记录或选图的业务服务器。平台保存的成绩等信息按平台规则管理。

您主动通过邮箱提交的隐私请求及联系信息，仅用于核实、答复和处理该请求，在实现该目的及满足法定义务所需的最短期限内保存；不再需要时删除或匿名化。电子邮件由您选择的邮件服务提供商传输和保存。

开发者不主动将本地游戏业务数据传输至境外。设备、小游戏平台和邮箱服务各自处理的数据，应同时查阅其相应规则。停止运营时，我们将停止相关信息处理，并依法删除或匿名化开发者持有的信息；设备本地数据可由您清理。

三 我们如何使用 Cookies 和同类技术

游戏通过 Cocos 的本地存储接口保存进度和偏好；网页运行环境使用 localStorage 等本地存储机制。其目的为存档恢复和设置保留，不用于跨站广告追踪或个性化推荐。您可通过设备、浏览器或小游戏平台清除对应存储，但可能失去进度和设置。

游戏业务代码未设置用于广告推荐的 Cookies。承载本政策的 GitHub Pages 网页未加入开发者统计脚本、广告代码或表单；网站托管服务可能按其规则处理访问连接信息，详见 GitHub 隐私声明。

四 我们如何共享 转让和公开披露您的个人信息

开发者不出售个人信息，当前未委托第三方对本地游戏记录开展广告投放、营销画像或远程统计分析。平台好友榜与您主动发起的分享涉及的信息及范围已在第一节说明；我们不会据此读取通讯录或自动向好友发送消息。

除实现您主动使用的平台功能、取得必要授权或依法履行义务外，不向其他主体提供个人信息。需委托处理时，将依法约定目的、期限、方式、信息类型和保护措施并监督受托方；需共享或公开披露时，将依法履行告知及相应同意义务。

如因合并、收购、资产转让等涉及个人信息转移，将依法告知接收方名称及联系方式，要求其继续履行个人信息保护义务；变更原处理目的、方式时依法重新取得同意。公开披露仅在取得必要授权或法律规定的情况下进行。法律允许免于同意的处理严格限于适用的法定范围。

请谨慎分享包含您或他人个人信息的图片或内容；涉及他人信息时，应取得合法授权。

五 第三方产品或服务如何获得您的个人信息

当前游戏业务版本未配置有效广告位，不提供实际激励视频广告；代码中预留的广告入口不能据此发放模拟广告奖励。游戏未接入独立账号注册、手机号登录、第三方统计 SDK 或支付 SDK。

游戏使用 Cocos Creator 引擎及小游戏运行适配代码提供画面、声音、资源加载和本地存储能力。TapTap 提供下载及小游戏运行平台服务，其平台侧的信息处理规则请查阅您使用的 TapTap 客户端或平台展示的隐私政策。使用平台服务不等于本游戏已经集成全部 TapSDK 功能。

未来如接入广告、账号、实名验证、支付或统计服务，我们将先更新本政策及对应第三方信息清单，明确提供者、处理目的、信息类型、权限和隐私政策链接，并在需要时取得您的同意。

当前组件和平台功能说明：

- Cocos Creator 3.8.8 引擎及运行适配代码：提供渲染、声音、资源加载、本地存储和基础设备适配；读取屏幕尺寸、像素比例、平台类型及系统版本等运行信息。
- 平台开放数据和分享接口：在接口可用时处理成绩及分享参数，并在平台开放数据域展示好友昵称、头像和成绩；详见第一节。这不是独立接入全部 TapSDK 服务。
- GitHub Pages：仅托管本政策网页，其服务信息见第三节的 GitHub 隐私声明。

目前没有已配置启用的广告 SDK、支付 SDK 或第三方统计 SDK 清单。未来实际接入时，将列明准确的服务名称、提供者、使用目的、信息类型、权限及隐私政策链接，不以通用列表代替实际接入清单。

六 我们如何保护您的个人信息

我们通过本地处理、按功能读取信息及限制用途减少信息暴露。我们不要求您通过邮箱提供密码、完整身份证照片等与隐私请求无关的信息。请妥善保管设备，避免向不可信对象提供存档或敏感图片。

网络和设备环境存在风险。如发生涉及个人信息的安全事件，我们将及时采取补救措施，依法告知事件情况、可能影响、已采取和拟采取的措施，以及您可采取的防范建议，并按规定向有关部门报告。无法逐一通知时，将依法采用公告等方式告知。

七 您如何管理您的个人信息

您可以在游戏中查看进度和成绩、修改声音及动效等设置，通过系统或平台管理权限，并通过清除本地数据删除本地游戏记录。当前游戏没有开发者独立账号，因此没有独立账号注销入口；平台账号的管理或注销请通过平台办理。

如需了解、查阅、复制、更正或删除与您相关的信息，撤回授权，或提出隐私投诉，请联系 xiaojiaenen@163.com。为防止他人冒用，我们可能请求必要的身份或请求关联信息；请勿发送与请求无关的身份证照片、密码等敏感内容。我们将依法处理并原则上在15个工作日内回复；确需延长时说明原因。

撤回可选权限后，对应选图或拍照功能可能不可用，不影响普通关卡，也不影响撤回前基于有效授权已进行处理的效力。平台排行榜数据的删除须通过相应平台渠道办理；您可联系开发者获取协助，开发者不能通过清除本地存档代替删除平台数据。

在违法处理、目的已实现或不再必要、您撤回同意、停止服务等法律规定的情形下，您可请求删除相关信息。对于依法暂不能删除的信息，我们将停止除存储和必要安全保护以外的处理。若依法不能满足请求，将说明理由及可用的救济途径。

八 我们如何处理未成年人的个人信息

未满14周岁的儿童应由监护人阅读本政策，并在监护人同意和指导下使用游戏。我们不主动要求儿童提交身份、联系方式等信息。若监护人发现儿童未经同意向开发者提供个人信息，可通过上述邮箱申请核实和删除。平台实名、防沉迷等服务以实际接入及平台要求为准。

未满18周岁的用户应在监护人的指导下使用游戏。对于未满14周岁儿童的个人信息，将依法取得监护人同意并进行专门保护；只在法律允许、监护人同意或保护儿童所必需的范围内处理。发现超出合法依据处理儿童信息时，将核实并及时删除。监护人可通过第十节邮箱提出保护请求。

九 本隐私政策如何更新

当功能或信息处理方式发生变化时，我们将更新本政策并标注更新日期；涉及处理目的、信息种类、提供对象等重大变化时，将通过适当方式告知，并在法律要求时重新取得同意。您可以通过游戏内公布的隐私政策入口或商店隐私政策链接查看适用版本。

重大变更包括处理目的、方式、信息种类、提供对象或权利行使渠道等发生重大变化。未经您的必要同意，不削减您依法享有的权利。历史版本通过政策公开仓库的版本记录保留，可联系开发者协助查阅。
